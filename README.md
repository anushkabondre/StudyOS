# StudyOS

StudyOS is an AI-powered study platform that helps students organize, search, and interact with their study materials.

## Features (Planned)

- Google Authentication
- Email Authentication
- Smart Document Vault
- OCR for Images and PDFs
- AI Semantic Search
- AI Chat with Documents
- Smart Study Assistant
- Assignment Assistant
- Semester Timeline

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- FastAPI
- PostgreSQL
- ChromaDB

### AI
- OpenAI
- LangChain
- PaddleOCR
